# 사주노트 7.0

## 배포 방법

1. 기존 GitHub 저장소를 백업합니다.
2. 이 폴더 안의 index.html, js/, css/, saju-icon.png, saju-share-cover.png를 저장소 루트에 올립니다. ZIP 파일 자체를 올리거나 폴더를 한 겹 더 중첩하지 마세요.
3. Cloudflare Pages의 기존 설정(Framework None, build command 비움, 저장소 루트 출력)을 유지합니다.
4. 배포가 끝나면 기존 주소를 새로고침합니다. 이전 화면이면 강력 새로고침을 합니다.

배포는 수행하지 않았습니다. 이 ZIP이 배포용 소스입니다. 기존 프로젝트의 도메인을 그대로 사용해야 이전 브라우저 저장 정보에 접근할 수 있습니다.

## 달라진 점

- 첫 결과는 나의 캐릭터·일상·상황 반응. 상세 분석은 ‘자세히’ 아래 유지.
- 궁합은 관계 캐릭터와 선택형 상황극 우선. 지수·전통 해석은 접어서 보존.
- 어두운 노트 디자인, 일관된 오행 SVG 캐릭터, 적은 금색 강조.
- 일간 기본 문장에 주요 십신 5범주의 상황별 표현 추가. 무작위 생성 아님.
- 같은 성향 조합은 공통점과 겹치는 갈등 지점을 명시.
- 1080×1350 / 1080×1920 PNG 카드, 미리보기, 별명 선택, 생년월일 제외.
- 지원되는 HTTPS 모바일 환경에서는 시스템 공유. 미지원이면 이미지 다운로드.
- ‘내 노트에 담기’, 공감/다른 점 기록, 개인 메모, 삭제, JSON 백업/복원.
- 30일이 지난 노트는 노트 화면에서 재확인 질문 표시. 외부 알림은 보내지 않음.
- 이름 선택 입력. 내 정보를 유지하며 궁합으로 이어짐.
- 마지막 조회 자동 복원은 유지. 최근 본 사람 자동 추가는 중단하고 수동 저장으로 정리.
- 공개 화면의 판매/출고 검수 문구 제거, 브랜드 사주노트로 통일.
- 중복된 구버전 파일 대신 실행 파일을 js/와 css/로 분리.

## 데이터와 계산

기존 saju-profiles, saju-last 저장 키를 유지합니다. 노트는 saju-notes-v7에 별도 저장합니다. 데이터는 브라우저별로 분리되며 기기 동기화는 없습니다. 노트 백업에는 별명·메모가 포함됩니다. 입력 화면의 전체 삭제는 프로필·마지막 결과·노트를 함께 삭제합니다.

양력만 지원합니다. 음력 변환·해외 출생·진태양시 및 절기 경계 정밀도 개선은 이번 변경 범위에 포함하지 않았습니다. 계산 엔진의 원래 한계가 유지됩니다. 사주의 정확성이 향상됐다는 의미는 아닙니다.

해석 문장은 전통 명리 기반 오락·자기성찰 콘텐츠입니다. 실제 성격이나 관계의 결과를 검증한 점수가 아닙니다. 같은 일간/주요 십신 조합은 같은 문장이 나올 수 있습니다.

## 검증과 남은 확인

- JS 문법 확인.
- 생년월일·출생시간 6개 사례의 원국 결과가 원본과 동일.
- 6가지 관계 유형의 궁합 계산 결과가 원본과 동일.
- 전체 분석 섹션, 궁합의 상황극/상세 순서, 날짜 유효성, HTML 문자 이스케이프 확인.
- 노트 저장/중복 방지/삭제 및 마지막 결과 복원 확인.
- 네이티브 Canvas로 두 규격의 PNG 생성 및 한글 카드 확인.
- 브라우저 자동화 환경은 제공되지 않아 실제 모바일 레이아웃, Safari/Chrome 공유 시트, PDF 인쇄는 아직 실제 기기에서 검증하지 못했습니다.

배포 후 휴대폰에서: 새 입력 → 내 이야기 → 내 카드 저장 → 궁합 → 내 노트 → 새로고침 복원 순서로 확인하세요. iOS에서는 이미지 다운로드가 사진 앱에 자동 추가되지 않을 수 있습니다. 공유 메뉴나 파일 앱에서 저장하세요.

로그인·유료화·원격 분석/추적·자동 SNS 게시 기능은 없습니다. 홍보 게시물은 운영자가 직접 올립니다.
